# Image Captioning Model

End-to-end pipeline to build an image captioning model on the COCO dataset stored in Google Cloud Storage (GCS). The workflow:

1. Stream COCO images from GCS, preprocess them, and extract VGG19 feature vectors.
2. Build a captioning model (encoder + attention + decoder) and train on the extracted features.
3. Save artifacts locally and upload models/tokenizer/metadata to GCS.

## Requirements

- Python 3.10
- Conda (recommended)
- Google Cloud project + service account credentials
- COCO dataset available in GCS

## Setup

1. Create and activate the Conda environment:

```bash
conda env create -f conda_env.yaml
conda activate tf-clean
```

2. Install the package in editable mode:

```bash
make src_importable
```

3. Create `config.yaml` (project-level paths):

```bash
make config_yaml
```

This generates `config.yaml` in the repo root and sets `PROJECT_HOME_PATH` and `CONFIG_YAML_PATH`.

4. Configure environment variables:

```bash
cp .env.template .env
```

Update `.env` with your GCP project, bucket names, COCO paths, and output paths.

5. Place your GCP service account key at:

```
credentials/gcp/service_account.json
```

## Usage

### 1) Create feature vectors + caption dictionary

```bash
python3 create_feature_vector.py
```

This will:
- Read COCO label/caption metadata from GCS
- Validate caption entries
- Save a compressed caption dictionary to GCS
- Stream images from GCS, extract VGG19 `block5_conv4` features, and store them as `.npz` in GCS

### 2) Train the captioning model

```bash
python3 create_image_captioning_model.py
```

This will:
- Read caption dictionary + feature vectors from GCS
- Train an encoder/decoder model with attention
- Save artifacts locally under `artifacts/image_captioning`
- Upload models/tokenizer/metadata to `gs://$GCS_OUTPUT_BUCKET_NAME/artifacts/image_captioning`

Notes:
- Training epochs are controlled by `EPOCHS` and a development `break_limit` in `create_image_captioning_model.py`.
- Test images are loaded from the `test_images` prefix in the output bucket, and generated captions are written to `artifacts/image_captioning/test_image_captions.jsonl`.

## Configuration Reference

### `config.yaml`

Generated by `make config_yaml` and read by `src/image_captioning_model/settings/config.py`.

### Environment variables

Defined in `.env` and loaded by `src/image_captioning_model/settings/env.py`:

- `GCP_PROJECT_ID`
- `GCP_PROJECT_LOCATION`
- `GCS_COCO_DATASET`
- `COCO_BUCKET_NAME`
- `GCS_OUTPUT_BUCKET_NAME`
- `GCS_OUTPUT_DIR`
- `GCS_OUTPUT_CAPTION_OBJECT_NAME`
- `GCS_OUTPUT_TEST_IMAGE_FOLDER`
- `COCO_TRAIN_IMAGE_FOLDER`
- `COCO_TRAIN_LABEL_METADATA`
- `COCO_TRAIN_CAPTION_METADATA`

## Project Structure

- `create_feature_vector.py`: builds caption dict + VGG19 feature vectors in GCS
- `create_image_captioning_model.py`: trains captioning model and saves artifacts
- `src/image_captioning_model/vision/`: preprocessing + VGG19 feature extractor
- `src/image_captioning_model/coco/`: COCO JSON readers/validators
- `src/image_captioning_model/GCP/`: GCS and BigQuery helpers
- `artifacts/`: local training outputs (models/tokenizer/history)

## Troubleshooting

- If you see `... not found` values for env vars, verify `.env` and reload your shell.
- Ensure `config.yaml` points to the correct project root.
- Confirm the service account key exists at `credentials/gcp/service_account.json`.
